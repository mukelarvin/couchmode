# CouchMode

Merges an Android gaming handheld's onboard controls and any external
controller (Bluetooth, 2.4GHz dongle, wired) into one stable virtual gamepad,
so docking to a TV doesn't mean reconfiguring every emulator's Player 1
binding.

- Full design/architecture: [`spec.md`](./spec.md)
- Build phases and current status: [`PLAN.md`](./PLAN.md)

Distributed via GitHub Releases + [Obtainium](https://github.com/ImranR98/Obtainium).
No Play Store.
